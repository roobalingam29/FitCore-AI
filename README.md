# FitCore AI – Smart Gym Management System

FitCore AI is an enterprise-grade smart gym and fitness center operations system featuring real-time KPI dashboards, Google Gemini 3.6 Flash AI operations insights, role-based access control (Admin, Trainer, Member), QR turnstile check-in simulator, membership tier billing, pro-shop inventory tracking, and exportable financial reports.

---

## Key Features

1. **Role-Based Access Control (RBAC)**: Switch seamlessly between Admin, Trainer, and Member view modes with role-tailored navigation bars.
2. **AI Gym Operations Advisor**: Powered by Gemini 3.6 Flash to predict member churn risks, optimize gym floor peak capacity, and generate custom progressive hypertrophy protocols.
3. **Turnstile QR Attendance Terminal**: Simulated camera scanner and manual member ID lookup.
4. **Member & Trainer Roster**: Full CRUD with plan linking, emergency contacts, and performance ratings.
5. **Pro Shop Inventory**: Low-stock alert badges, SKU adjustment buttons, and cost margin calculation.
6. **Financial Ledger**: Invoices, payment methods (Credit Card, Bank Transfer, Cash, UPI), and payment statuses.
7. **Analytics & Reports**: Visual Recharts revenue trajectory, peak occupancy bar charts, and CSV report exporter.

## Quick Start Commands

```bash
# Install Node dependencies
npm install

# Start Express + Vite Dev Server
npm run dev

# Build for Production
npm run build
```
